Security Boundary

The extension package is designed so reviewers can inspect the local MVP behavior from source, built output, proof artifacts, and release-candidate package files.

Package Claims

  • No live portal requests.
  • No unattended booking.
  • No remote code.
  • No hidden submit path, broad host access, or private page dump.
  • No live provider webhook or bot API call.
  • Debug exports are redacted and checked for banned sensitive fields.
