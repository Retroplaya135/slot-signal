Slot Signal Trust Center

Privacy Notice

This final local reviewer MVP stores community slot-signal records, filters, notification status, queue integrity metadata, provider-safe outbox records, public-estimate context, and redacted debug exports.

Boundaries

  • No live portal requests.
  • No unattended booking.
  • No portal passwords, cookies, payment data, passport scans, or DS-160 identifiers are stored.
  • No email, Telegram, or Slack provider credentials are configured in this package.
  • No remote code is loaded or executed by the extension package.

Sharing

Reviewer data stays local unless a future feedback flow asks the user to submit a redacted debug export. That upload flow is not implemented.
