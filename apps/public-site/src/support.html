Support should start from a redacted export.

The extension includes support export controls for troubleshooting without exposing portal credentials or private identity data.

Direct answer

Need help? Export support data from the extension advanced area and send only the redacted file to the beta operator.

Support checklist

Use this path for beta review before store submission or public release.

  1. Confirm access code

    Verify your issued access code and extension access key are entered correctly.

  2. Run a manual signal test

    Submit sanitized visible metadata and confirm whether a browser alert is generated.

  3. Export support data

    Use the extension advanced area. Do not send portal passwords, one-time codes, or official account screenshots unless specifically required and safe.
